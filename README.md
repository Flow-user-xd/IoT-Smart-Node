# ESP32 Smart Environment Controller
An IoT-based system to monitor temperature, humidity, and gas/smoke levels using an ESP32. Includes an Auto/Manual mode for intelligent relay switching.

## Hardware Used
* ESP32 Development Board
* DHT11 Temperature & Humidity Sensor
* MQ2 Gas/Smoke Sensor
* IR Sensor
* 2-Channel Relay Module

## Features
* **Live Monitoring**: View metrics on the Blynk IoT app.
* **Auto Mode**: Activates exhaust fan automatically at 30°C or if smoke is detected.
* **Manual Mode**: Control lights/appliances via physical IR sensor or mobile app.
